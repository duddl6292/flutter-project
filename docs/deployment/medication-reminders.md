# 복약 알림 스케줄러

처방에서 선택한 복약 시각은 다음과 같이 고정됩니다.

- 아침: 07:00
- 점심: 12:00
- 저녁: 18:00

백엔드 컨테이너에서 아래 명령을 5분마다 실행하면 해당 시간대의 환자 인앱 알림을 생성하고 등록된 앱 기기로 FCM 푸시를 발송합니다.

```text
python manage.py send_medication_reminders
```

운영 환경에서는 백엔드와 동일한 이미지·환경 변수·서비스 계정을 사용하는 Cloud Run Job을 만들고 Cloud Scheduler에서 5분 간격으로 실행합니다. 명령은 날짜와 복약 일정 ID로 중복을 방지하므로 같은 시간대에 재시도해도 알림이 중복 생성되지 않습니다.

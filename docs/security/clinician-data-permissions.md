# 의료진 데이터 권한 정책

담당 환자 또는 협진 참여 관계는 향후 업무 모델에서 객체 권한으로 검증한다. 현재 단계에서는 객체 권한을 임의 구현하지 않는다.

| 데이터 | 조회 | 생성 | 수정 | 삭제 |
| --- | --- | --- | --- | --- |
| 환자 기본정보 | 담당 환자만 | 불가 | 제한적 | 불가 |
| 예약 | 담당 일정 | 가능 | 가능 | 취소 상태 처리 |
| 진료 기록 | 담당 환자 | 가능 | DRAFT만 | 불가 |
| 처방전 | 담당 환자 | 가능 | 발행 전만 | 중단 상태 처리 |
| 검사 결과 | 담당 환자 | 가능 | 공개 전만 | 무효 상태 처리 |
| 협진 | 참여 건 | 가능 | 상태·답변 | 취소 상태 처리 |
| CT 분석 | 담당 환자 | 요청 가능 | 공개 상태만 | 불가 |
| 사용자 역할 | 불가 | 불가 | 불가 | 불가 |
| 감사 로그 | 제한 조회 | 불가 | 불가 | 불가 |

상태 흐름:

```text
진료 기록: DRAFT → FINALIZED → ADDENDUM
검사 결과: DRAFT → REVIEWED → RELEASED
처방: DRAFT → ISSUED → DISCONTINUED
예약: REQUESTED → CONFIRMED → COMPLETED 또는 CANCELLED
```

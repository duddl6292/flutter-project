# 프론트엔드 Mock 데이터 원칙

- Django API가 완성되기 전까지 Flutter와 React는 Mock 데이터로 개발할 수 있다.
- 실제 환자 이름, 전화번호, 주민등록번호, CT 파일을 사용하지 않는다.
- 모든 Mock 데이터는 완전한 가상 데이터여야 한다.
- Mock 데이터는 각 프론트엔드의 `shared/mock/`에 보관한다.
- API 완성 후 화면을 바꾸는 대신 Mock repository를 실제 API client로 교체할 수 있도록 분리한다.
- 화면 컴포넌트 내부에 대량의 Mock 데이터를 직접 작성하지 않는다.
- 날짜와 상태값은 프로젝트 안에서 일관된 형식을 사용한다.
- API 계약이 확정되기 전 Mock 구조를 공식 API 계약으로 간주하지 않는다.

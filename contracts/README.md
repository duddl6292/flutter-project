# API Contracts

모바일, 의료진 웹, Django API, 추론 서비스 사이의 요청·응답 예시를 관리합니다.
예시는 식별 불가능한 완전한 가상 데이터만 사용합니다.

- `examples/`: JSON 등 실행 가능한 계약 예시
- `inference-request.example.json`: Django에서 Gateway로 보내는 strict v1 요청
- `inference-response.example.json`: Gateway가 반환하는 strict v1 응답
- `mosec-api.md`: Gateway와 MOSEC 사이의 내부 API 계약
